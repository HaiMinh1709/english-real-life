ENGLISH FOR REAL LIFE V2.0
120 practical conversation lessons / 20 topics.

Run locally:
1. Open this folder in VS Code.
2. Right-click index.html -> Open with Live Server.
3. Keep Clara as Speaker A and Liam as Speaker B if those voices are available.

Main modes:
READ: English + IPA + Vietnamese.
LISTEN: hide transcript and listen to full dialogue.
SHADOW: app reads one sentence, pauses, then continues.
SPEAK: app reads alternating prompts and leaves your turn for a spoken response.
REVIEW: saved phrases return on a 1-3-7-14-30 day schedule.

Your V1.x saved phrases/completed lessons are migrated automatically on the same browser origin.
